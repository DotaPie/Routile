# Routile

Draw an area on a map and get a route that drives every road inside it, exported as GPX for a navigation app such as OsmAnd, Locus Map or Garmin.

A simple tool that I built because I needed to systematically scan the roads in a certain area. It is a static web page with no backend, build step or API keys. Road data comes from OpenStreetMap via the Overpass API and all routing runs in the browser.

Road data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL). Map rendering by [Leaflet](https://leafletjs.com/), zip export by [JSZip](https://stuk.github.io/jszip/).
